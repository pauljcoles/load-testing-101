# The Hole

A small load testing calculator that explains capacity with blocks and a hole.

- **Blocks** are requests.
- **The hole** is your pods and load balancer.
- Questions: how big is the hole, how many blocks fit through at once, and how long until they are all through?

It is built on Little's Law: throughput = concurrency / response time.

Live page: https://pauljcoles.github.io/load-testing-101/
